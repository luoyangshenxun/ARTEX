## 合并算法

待还原的最小算法包括：

1. beta 来源的读取顺序；
2. 空值、重复值和冲突值的处理；
3. token 的排序或保留插入顺序；
4. `Headers` 写入时的字符串序列化；
5. CLI 层与 SDK 层是否各自追加一次；
6. 版本升级时 token、默认集合或条件分支的变化。

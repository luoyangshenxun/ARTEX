## 算法说明模板

每个计费或身份字段补充一段可执行的伪代码，并明确：

```text
input:
normalization:
branch conditions:
composition:
encoding:
persistence:
failure/fallback:
source:
version:
evidence:
```

需要特别区分：

- CLI 本地生成的标识与服务端响应/回填的标识；
- 请求体字段与 HTTP 头字段；
- 用户账号、安装实例、会话和单次请求的作用域；
- 计费标签的业务名称与实际参与算法的字段；
- system prompt 的固定片段、条件片段、版本片段和用户输入边界。

不得把脱敏值、随机 ID 或一次抓包中的 system prompt 直接写成算法。
